# 1.8 秒连续开场形变

流程：硬币落入竹节 → 同一竹节连续收窄、长高 → 侧竹与叶片展开 → 每日一句。

| 时间 | 动作 |
|---|---|
| 0–310ms | 硬币落入投币口，被前沿裁切遮住 |
| 230–1450ms | 竹身宽度、长度、顶部曲线连续变化，收小后向上生长 |
| 310–800ms | 内嵌竹口收拢到竹尖，全程裁切在竹身内部 |
| 660–1560ms | 侧竹从固定根部依次长出 |
| 930–1600ms | 叶片随枝干展开 |
| 1600–1800ms | 保持完整竹林，随后显示每日一句 |

`intro-motion.js` 是约 6.6KB 的连续 SVG 渲染器。竹筒与主竹的六条对应曲边描述同一侧面、顶面和底面，使用一致拓扑插值；高度采用一条连续的收缩到生长曲线。各段不再分别减速到零。SVG 节点只创建一次，每次 requestAnimationFrame 直接按实际时间更新几何属性，不再取整到预制帧或替换整个 SVG。

竹口、投币口与竹节纹理裁切到当前主体。主竹不依靠透明度交叉淡化，侧竹从同一根部缩放生长；没有脱离主体的圆片。不依赖 Aksharam、运行时图片服务或动画库。

画面保持 300px，窄屏限制 86vw。底部 wordmark 保持安静。首尾形状来自 intro-frames.js；修改后运行 `npm run intro:build`。scripts/build_intro_motion.py 保留兼容入口，调用 Node + jsdom 导出八张实际渲染器的采样 SVG；它不再生成逐帧播放数组。

播放器使用 requestAnimationFrame 和 1800ms 截止计时器。跳过、Escape、重播均取消旧帧和计时器；减少动态效果直接进入每日一句，切后台结束开场。morph-preview.html 提供重播和连续时间拖动。

## 简洁 Karma 入场

页面只保留一句原创短句与 Enter Community 按钮。文字用 720ms 轻微上浮、3px 模糊到清晰及淡入；按钮延迟 180ms 后用 460ms 上浮淡入。无卡片、额外标题、图标或底部 wordmark。

减少动态效果立即显示内容；关闭、重播和切后台取消旧效果。`?view=karma` 直接预览。开场与短句均不代表真实支付、不改资金池或 streak；用户点击按钮后进入主页。
