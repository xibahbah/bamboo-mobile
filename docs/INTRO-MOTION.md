# 1.8 秒开场形变

流程：硬币落入竹节 → 竹节收小 → 变成竹笋并长高 → 叶片展开、竹林完成 → 每日一句。

| 时间 | 动作 |
|---|---|
| 0–310ms | 硬币落入投币口，被前沿裁切遮住 |
| 310–560ms | 竹节向底部锚点收小到 58% |
| 560–850ms | 竹节主体通过有符号距离场变为竹笋 |
| 850–1420ms | 同一轮廓变细并向上长高，侧竹从底部依次长出 |
| 1110–1620ms | 叶片展开；竹节纹理只显示在主体内部 |
| 1620–1800ms | 保持完整竹林，随后显示每日一句 |

沿用之前项目的经验：对复杂轮廓使用距离场和等值线，避免不相干顶点一一对齐造成扭转；几何提前烘焙，浏览器只播放。细长竹子先在相同高度里计算距离场，再按固定底部伸展，避免细长目标直到末尾才突然出现。主体没有图片叠化或透明度替换；竹节细线等附属细节允许隐去。

`intro-motion.js` 为 109 帧矢量，约 320KB（未压缩）。不依赖 Aksharam 目录、运行时图像服务或动画库。源码在 scripts/build_intro_motion.py。

画面从 240px 放大到 300px，窄屏用 86vw 限制；底部 wordmark 保持安静。首尾帧 SVG 同步更新。

播放器使用 requestAnimationFrame 和 1800ms 截止计时器，跳过、Escape、重播均取消旧帧和计时器。减少动态效果直接进入每日一句；切到后台也结束开场。生产主页移除首尾帧切换按钮；morph-preview.html 保留重播和时间拖动，方便设计检查。

开场硬币不代表真实支付，不更新资金池或 streak。每日一句之后仍由用户进入主页。

## 竹口与 Karma 衔接修订

移除了悬浮圆片：顶面改为内嵌曲面，投币后几何收拢；顶面、投币口与竹节纹理都裁切在当前主体轮廓内，不能在竹身外漂浮。竹口不再使用透明度淡出。

竹林完成后显示 A LITTLE KARMA 卡片，520ms 轻弹进入，叶片与文字做短暂错开入场。底部 bamboo 与开场保持同一位置、大小。阅读后点 Enter community 进入主页；关闭或减少动态效果可直接跳过动效。动画取消覆盖快速关闭、重播和后台切换。

`?view=karma` 可以直接预览当天卡片；完整体验使用 app 首页，不会在竹林尾帧停住。
