# Bamboo 社区头像壁纸｜功能说明

**功能名：Community Compassion Wallpaper**  
更新日期：2026 年 11 月 7 日  
状态：独立网页交互原型；真实成员、服务器数据与正式应用路由仍需整合。

## 1. 功能目的

将本地区持续参与善行的成员展示为紧密相连的头像泡泡，让用户直观看到身边的 **compassion（慈悲与关怀）**。

每个人的头像大小相同，不以捐款金额或连续天数决定视觉权重。仅展示达到连续善行门槛、且主动同意公开的成员。

## 2. 最终视觉要求

- **二维壁纸、固定正面视角**，适合横向大画面，也适配手机竖屏。
- 白色或极浅背景，简洁、轻透，有类似 Apple 界面的细腻泡泡质感。
- 头像为圆形，泡泡等大，紧密相接，像 bubble wrap 一样聚集。
- 泡泡外缘相接，照片主体不互相遮挡。
- 普通浏览、持续播放及触碰时，各头像与邻居的位置关系保持固定。
- 只有光影上的漂浮感，不进行三维旋转或镜头运动。
- 页面不放链接、底部导航、详情弹窗、拖动、缩放或视角切换控件。
- 不显示捐款金额、排行榜或捐助者等级。

### 页面文字布局

| 位置 | 内容 | 行为 |
| --- | --- | --- |
| 左上 | 设置中选定的具体地区 | 只读显示，不在壁纸内切换地区 |
| 上方中央 | `15 天以上 · 连续善行` | 淡雅、融入背景，表示展示门槛 |
| 左下 | 符合条件的示意成员总数 | 当前为演示说明；不是当前屏幕完整可见头像数量 |
| 右下 | 虚构头像说明 | 说明当前使用模拟成员及重复头像素材 |

**注意：** 上方的 15 天表示进入壁纸的资格门槛，不是当前用户本人的 streak。

## 3. 动效与触碰

### 环境动效

缓慢改变泡泡的高光透明度和阴影，使其看起来轻轻漂浮。当前每个泡泡的光影循环为 9–14 秒，错开播放时间。

### 触碰反馈

触碰时出现约 0.9 秒的柔和光晕，然后恢复。键盘聚焦后按 Enter 或空格也能触发反馈。

### 必须保持的约束

- 不改变头像的位置或尺寸。
- 不弹开、不碰撞、不互换位置。
- 不根据触碰重新排列成员。
- 不通过平移、缩放或透视变换模拟漂浮。
- 系统开启「减少动态效果」时，关闭环境动画及触碰光晕动画。

浏览器尺寸或所选地区变化时允许重新布局。这与普通触碰时保持位置固定是两种不同情况。

## 4. 地区与展示资格

成员必须同时满足：

```text
currentStreakDays >= 15
AND optedIn == true
AND member belongs to the selected community
```

地区来源：**Account → ☰ → Your community**。壁纸不请求 GPS，也不显示成员的精确地理位置。

- 默认地区：San Diego County。
- 现有示例地区：North Park、City Heights、Chula Vista、La Jolla、Oceanside、Encinitas。
- 县级地区包含其下的示例社区；选择具体社区时仅显示该社区成员。
- 地区偏好目前保存在同一浏览器中，并通过存储事件同步到其他已打开的同源页面。
- 当前 streak 低于 15 天或撤回公开同意时，正式版应及时停止展示该成员。
- 没有符合条件的成员时，显示：**「这里的善意，等你一起开始。」**

正式版应以服务器验证后的连续天数、地区归属及公开同意状态作为筛选依据。

### 本地运行

在 `bamboo-mobile-main` 文件夹内运行：

```sh
python3 -m http.server 5187 --bind 127.0.0.1
```

同一台电脑打开：

- 壁纸：http://127.0.0.1:5187/community-wallpaper.html
- 地区设置：http://127.0.0.1:5187/account-location.html#location

若出现启动语录，先点击继续，再进入设置。修改地区后，已打开的壁纸会更新。

队友需要完整代码与对应素材，只有这份 MD 无法运行演示。

## 6. 当前实现细节

- 使用六角密排，圆形泡泡在几何上相切。
- 桌面直径为 72px，窄屏直径为 58px；同一视图内全部相等。
- 成员按固定次序分配到中心向外的坐标，不做实时物理模拟。
- 用 `ResizeObserver` 响应容器尺寸变化。
- 用 `bamboo-location-change` 响应地区变化。
- 头像边缘可以被裁切，形成壁纸延伸出屏幕的感觉；页面不提供平移查看其他区域。

地区偏好存储键为 `bamboo-community-location-v1`。当前默认县级视图有 180 条虚构记录，重复使用 36 张头像；每个有成员的示例社区为 36 条记录，Encinitas 为零。**这些人数不代表真实居民或真实捐款情况。**

## 7. 正式接入建议

服务端成员数据至少需要以下字段，名称可按团队现有 API 调整：

```json
{
  "id": "stable-member-id",
  "displayName": "Member name",
  "avatarUrl": "https://example.org/avatar.jpg",
  "communityId": "north-park",
  "countyId": "san-diego-county",
  "currentStreakDays": 15,
  "optedIn": true
}
```

此结构是建议，不是已实现的 API。

接入时需要：

1. 用真实用户数据替换硬编码示例成员及头像图集。
2. 保留稳定成员 ID，避免后台刷新导致仍在画面中的成员随意换位；当前原型尚未实现增量数据更新。
3. 为真实显示名称使用安全文本渲染，不直接拼接进 HTML。
4. 将地区偏好同步到账号；同设备本地存储不能替代账号设置。
5. 处理成员加入、退出、断签及撤回公开同意。
6. 确定真实人数超出屏幕容量后的选择与更新规则。当前壁纸可能裁切头像，不能保证所有合格成员都完整可见。
7. 统一正式应用入口。当前 Account 预览的 Map 路由仍指向旧版地区画布，需要替换为最新壁纸或嵌入统一页面。
