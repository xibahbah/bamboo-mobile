# Bamboo · 当前模拟版（2026-11-07）

以 Keith 最新要求为准：个人仍可发帖。此前“只有组织能发布”的方向已被替换。

## 打开与主页

开场自动播放 1.8 秒形变后显示每日一句，再按 Enter community 进入主页。Skip / Escape 可直接跳到每日一句；减少动态效果时跳过动画。首帧是较大的竹节存钱罐与投币口上方一枚硬币，尾帧保留五株极简竹林。淡绿底，底部只放 bamboo，无标语。没有修改 Aksharam，也没有把它的素材复制进来；只沿用“先确定两端轮廓，再做中间形变”的做法。

顶部固定：左侧导航按钮 / 中间 bamboo / 右侧当前 streak。

首页可自然滚动，没有卡片阴影堆叠。For you 混合组织与个人故事；Organizations 只列组织；Stories 只列个人故事。当前是八条预置演示帖加本地个人故事，滑到底有结束提示，不伪装无限数据。后端接入后用 cursor 分页。

组织发布 need / update，说明需求、安排与帮助进度；个人发布 story / recipe / culture。个人主页分 Stories / Recipes / Culture，默认 Stories。食谱和文化内容不混进首页。组织主页直接列本组织公开帖子。

侧栏：Home、Location · San Diego、Shared pool、City kindness wall、Messages、Saved posts、Your profile、Settings，另有分享个人故事、捐款、求助入口。原底部导航已移除。

## 关键行为

- 点头像或作者 → 对应个人或组织主页；个人页面可切换三栏。
- 分享故事 → 本地发布并回首页；分享食谱/文化 → 自己主页对应栏。
- 关闭发帖弹窗保留草稿；自己的帖子可移除并立即撤销。
- 点赞、收藏可取消，均不增加 streak。
- 顶部 streak → 竹子成长详情；未完成当天捐款时可从弹窗进入模拟捐款。
- 捐款仍进共同资金池；帖子没有向某人直接付款的按钮。
- 原有 profile、map、finance、消息、上墙同意流程保留；消息与付款都是本地模拟。
- 侧栏使用原生 dialog：模态焦点、Escape 关闭、点击遮罩关闭，选页面后关闭并把焦点移到正文。

## 后端边界

组织身份是服务器字段，不接受客户端自报。个人不能发布组织求助/进展，组织成员也不能冒充其他组织。前端分类和隐藏选项只是模拟，不能承担授权。详见 BACKEND-HANDOFF.md。

所有预置个人、组织、故事、地点和资金均为示意。获取帮助不要求发帖；受助故事公开必须单独征得内容相关的同意。

## UX 自检

依据 design-everyday-things 快速诊断，当前模拟版暂评 9/10：入口、反馈、恢复、布局映射各 2/2；约束 1/2，因为真正的组织授权仍需后端。此为设计自检，不是用户测试评分。

本轮完整 morph 已实现；后端授权、真实支付与消息尚未实现。无 hover、环境动效或强制提醒。

## 每日一句

开场 → 每日一句 → 主页。当前自动执行：投币 → 竹节收小 → 轮廓形变成竹子 → 长成竹林 → 每日一句。投币是开场隐喻，不产生实际支付或 streak。

每日一句按 America/Los_Angeles 日期稳定选取，同一天重开不乱换；次日换一句，30 条循环。26 条 Bamboo 原创短句、4 条附来源的短引用。可通过关闭或 Enter community 立即离开。无假加载倒计时。见 DAILY-REFLECTIONS.md。

每日一句现为居中的 A LITTLE KARMA 浅色卡片：竹林后自动轻弹出现，阅读后 Enter community 进入主页。可直接用 ?view=karma 预览；开场依然为 1.8 秒。
